# Visual References

These four screenshots were supplied by the product owner during product discovery.

They are preserved so implementation agents can see the intended visual direction without depending on the original chat.

Files:

- `reference-01.png`
- `reference-02.png`
- `reference-03.png`
- `reference-04.png`

## What to take from them

Use them as inspiration for:

- terminal/TUI character;
- dense information layouts;
- mostly monospaced typography;
- near-black/dark surfaces;
- thin borders and separators;
- compact labels;
- restrained use of color;
- grid-based composition;
- technical, utilitarian feel.

## What NOT to do

- Do not clone any reference screenshot literally.
- Do not infer product features from visible content in the references.
- Do not treat their exact grid, colors, fonts, or dimensions as requirements.
- Do not add fake terminal decoration if it reduces usability.

The product requirements in `project/` and `docs/` are authoritative.
