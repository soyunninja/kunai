# Owner-specific Usage Preferences

These preferences describe the initial owner's intended personal setup. They are NOT global defaults for every account.

## Clock

Owner wants quick access to:

- Almería/local time;
- Tokyo time.

A generic new user's default Clock remains local-only; the owner can configure Tokyo as an additional zone according to the Clock widget design.

## Weather

Default personal Home use: Almería/local location.

Standard Weather remains one-location.

Travel use may include multiple Japanese places such as Tokyo, Osaka, and Hiroshima (and other places configured by the user).

## Finance

- EUR/JPY is a high-value currency pair.
- `AAPL` is an important Markets symbol example.

Do not hard-code these into every user's defaults.

## Travel

Japan is the primary Travel use case.

The owner values:

- multi-city weather;
- external travel links;
- Spanish -> Japanese translation;
- Japanese public holidays.

## Devices

Primary use is desktop and tablet.

Mobile use exists but is less frequent.
