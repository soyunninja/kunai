# Default Home

## Required content

A new user's Home MUST contain:

- Search;
- Local Clock;
- Local Weather;
- Bookmarks.

## Layout principle

The exact initial coordinates and legal sizes are intentionally left to the Phase 0004/0005 design because widget size contracts have not yet been approved.

The default layout should:

- put Search prominently near the top;
- keep Clock and Weather immediately visible;
- give Bookmarks enough space to be useful;
- remain visually balanced on desktop/tablet;
- create a deterministic device layout for first use.

Do not turn an illustrative mockup into an undocumented layout contract.
