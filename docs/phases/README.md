# Phase Briefs

These files define the intended development order and product scope for each major phase.

They are NOT the official generated SDD artifacts.

For each phase:

1. read its brief;
2. start an OpenSpec change with the listed change name;
3. let gentle-ai generate proposal/spec/design/tasks;
4. review/approve those artifacts;
5. apply;
6. verify;
7. archive;
8. update `project/context.md` and `project/phase-map.md`.

Do not implement a later phase merely because it is easy to bundle into an earlier one.
