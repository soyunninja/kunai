# MVP Non-goals

These features must not be added to the MVP without a new approved SDD change.

## Productivity/business

- projects;
- tasks;
- subtasks;
- timers/time tracking;
- clients;
- profitability;
- invoicing;
- team collaboration.

## Communication

- email reading/sending;
- Slack/chat;
- notification center.

## Infrastructure

- server uptime monitoring;
- website ping dashboards;
- Docker/VPS control;
- deployment control panels.

## Search

- universal internal search;
- bookmark search inside the Search widget;
- command palette;
- AI-powered search.

## Notes

- full notes database/product;
- folders/tags/backlinks;
- Notion-like editing.

## Travel

- train routing;
- Spain/Japan time conversion tool;
- saved phrasebook;
- event/matsuri feed;
- itinerary planner;
- booking management.

## Dev

No general toolbox catalog beyond the two approved Dev widgets.

## Platform

- browser extension;
- native mobile app;
- PWA/offline mode;
- desktop native app.
